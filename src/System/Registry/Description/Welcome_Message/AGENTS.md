# AGENTS.md - Welcome Message Registry

## Security & Anti-Dilution Directive
This directory contains the master registry for game welcome messages, accessible control tutorials, and game credits.
- **Protection**: Automated processes must NEVER simplify, truncate, or remove control instructions or Fairies Dreams & Fantasy authorship attribution.
- **Zero Omission**: Any update to control mappings must be registered here without hardcoded inline strings in UI components.
