# Opossum Master Design Attributes Registry & Specification

This module (`src/System/Registry/Characters/Opossums/Attributes/Design/index.tsx`) provides 39 high-precision design attribute lookup maps and visual preview mappings for all 32 crafted opossums (24 Sacred Large Jills and 8 Compact Jacks).

## Overview of the 39 Master Design Attribute Lookup Maps

1. **Skin_Color**: Biometric root skin color groups (`Alabaster`, `White`, `Peach_Apricot`, `Tan_Caramel`, `Honey_Dark_Brown`, `Dark_Toffee`).
2. **With_Patterns**: Pattern classification lookup (`diamond_pattern`, `circle_pattern`, `flower_pattern`, `stripe_pattern`, `saddle_pattern`, `spotted_pattern`, `none`).
3. **Fur_Color**: Exact fur color and pattern description for each opossum.
4. **Tail_Color**: Base tail color lookup.
5. **Tail_Color_With_Design**: Tail design details (spirals, fur layers, or solid tones).
6. **Nose_Color**: Nose coloration (all crafted Jills feature smooth noses without nostrils).
7. **Shoulder_Height**: Biometric shoulder height measurements.
8. **Body_Width**: Substantial body width measurements in inches.
9. **Body_Length_excluding_head_and_tail**: Torso length in inches.
10. **Full_Body_Length**: Total tip-to-tail length in inches.
11. **Head_Width**: Head width measurements in inches.
12. **Head_Height_excluding_ears**: Cranial height excluding ears.
13. **Full_Head_Height**: Full head height including upright/extended ears.
14. **Total_Height_excluding_ears**: Standing height excluding ears.
15. **Total_Height**: Full standing height including ears.
16. **Eye_Color**: Ocular coloration (`Blue`, `Light Green`, `Light-Blue`, `Dark-Green`, `Indigo`, `Sky Blue`, etc.).
17. **Snout_Length**: Scaling factors for snout geometry.
18. **Furry_Face**: Percentage of facial fur coverage (0% for all crafted Jills including Melissa, Jacinta, Camryn, Dale, Qi, Jamie).
19. **Accessories**: Jewelry, tiaras, glasses, and diamond necklaces.
20. **Tail_Length**: Tail length measurements in inches.
21. **Ear_Orientation**: Spatial ear placement (`Upright`, `Forward Leaning`, `Side Down`, `Downward`).
22. **Ear_Length**: Ear length classification (`Conventional`, `Medium`, `Long`, `Short`).
23. **Paw_Color**: Forepaw and hindpaw fur color.
24. **Paw_Pad_Color**: Paw pad coloration.
25. **Ear_Color**: Outer ear coloration.
26. **Inner_Ear_Color**: Inner ear pinna coloration.
27. **Ear_Color_With_Patterns**: Ear pattern details.
28. **Head_Fur_Color**: Cranial fur color.
29. **_Furry_Face_Color**: Facial fur tint for species with >0% facial fur.
30. **Body_Fur_Thickness**: Fur density and thickness ratings.
31. **Furry_Tail_Percentage**: Percentage of fur layer on tail.
32. **Paw_Size**: Paw volumetric size rating.
33. **Leg_Length**: Limb length rating.
34. **Paw_Width**: Paw stance width rating.
35. **Leg_Width**: Limb caliper width rating.
36. **Has_Elegant_Chatter**: Boolean flag for 64-bit DSP high-pitch vocal chattering.
37. **Has_Elegant_Trot**: Boolean flag for RK4 kinematic trot movement.
38. **Tail_Thickness**: Prehensile tail thickness rating.
39. **Visual_Mapping**: Direct rendering configuration objects (`bodyColor`, `outlineColor`, `scale`, `headHeight`, `noseColor`, `earColor`, `faceColor`, `bodyPattern`, `necklaceColor`) consumed by the 3D preview canvas in `System/UI/Opossum_Selection_Screen/Main/index.tsx`.
