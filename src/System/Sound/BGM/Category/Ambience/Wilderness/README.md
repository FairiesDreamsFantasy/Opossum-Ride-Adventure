# Wilderness Ambience Synthesizer (`System/Sound/BGM/Category/Ambience/Wilderness/`)

Provides procedural Web Audio API environmental soundscapes for World 4 Wilderness arenas:
- `startDesertWind`: Drifting thermal sand wind across desert basins & dunes.
- `startPlainWind`: Broad open-air grassland breeze across prairies, steppes, and tundra.
- `startForestWildernessAmbience`: Canopy leaf rustle and rhythmic woodland cricket/stream bed.
- `startWildernessCaveAmbience`: Subterranean karst/basalt/ice airflow resonance and water drip modulation.
