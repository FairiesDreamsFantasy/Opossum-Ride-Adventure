# Triangular Slate Stone Path (`System/Building_Blocks/Triangular_Stone_Path/`)

Ground-oriented flat triangular **Slate** stone paving architecture for Crop Field arenas:
- **Path Pavers:** Flat triangular slate stone blocks cycling across 36 curated colors (including corrected **Caramel**).
- **Edge Dividers:** 12-inch (`0.3048 m`) triangular stones along both path edges in **Red**, **Gold**, and **Green**, cleanly separating crop fields from the trail.
- **Acoustic Surface:** Mapped directly to `SURFACE_PROFILES.slate` (`1650 Hz` bandpass, `Q = 4.8`, `105 Hz` thud).
