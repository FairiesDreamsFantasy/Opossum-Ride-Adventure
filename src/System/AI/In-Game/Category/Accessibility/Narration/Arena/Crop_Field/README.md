# Crop Fields Narration Module (`Narration/Arena/Crop_Field/`)

Zero-fallback spatial orientation and audio-description module covering the Crop Fields arena (`crop_field`) and its 6 crop field subarenas:
1. `Wheat_Field` (`wheat_field`)
2. `Corn_Field` (`corn_field`)
3. `Barley_Field` (`barley_field`)
4. `Rice_Field` (`rice_field`)
5. `Oats_Field` (`oats_field`)
6. `Sorghum_Field` (`sorghum_field`)
