# Rider Narration Sub-Engine

## Overview
This module provides descriptive profiles for the Rider character. It articulates the identity and visual appearance of the person or fairy currently navigating the sanctuary.

## Functions
- `RiderNarrationEngine.compileProfile()`: Concatenates name, height, ethnicity, heritage, hair, outfit, and footwear into a cohesive identity string. Triggered by hotkey `Shift+R` during gameplay.

## Descriptive Standards
Descriptions are prefixed with "You as" to firmly establish the rider's perspective and role within the adventure. This module is protected by the **Audio-Description Integrity Shield**.
