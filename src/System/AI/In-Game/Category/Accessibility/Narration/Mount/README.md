# Mount Narration Sub-Engine

## Overview
This module is the definitive source for Opossum mount descriptions. It synthesizes complex biometric data and rich character lore into a seamless auditory profile.

## Functions
- `MountNarrationEngine.compileProfile()`: Aggregates skin color, ear orientation, body dimensions (shoulder height, width, length), fur patterns, and biographical lore. Triggered by hotkey `r` during gameplay.

## Integrity Standard
This module enforces the **Anti-Information Omission Policy** (Section 4 of `PROTECTIONS_NOTICES.md`). It ensures that 100% of the mathematical specifications from the `OpossumsAttributesDesign` registry are presented alongside the character's narrative history. Separation of data from lore is strictly forbidden.
