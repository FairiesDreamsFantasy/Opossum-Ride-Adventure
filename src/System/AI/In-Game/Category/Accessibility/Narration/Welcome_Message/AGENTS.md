# AGENTS.md - Welcome Message Narration Engine

## Security & Anti-Dilution Directive
This directory contains `WelcomeMessageEngine`, responsible for generating the game's initial accessible TTS welcome announcement.
- **Zero-Dilution Policy**: The welcome message must NEVER summarize or omit physical biometric mount descriptions. It must always include the un-diluted `MountNarrationEngine.compileRiddenOpossumProfile(opossum)` string.
- **Control Instruction Integrity**: Instructions for the Arden Denis and Cedella keyboard layouts, TTS stopping (`Ctrl`), chatter, POV toggle, and pause/resume must remain intact.
- Automated code reductions, simplifications, or stubbings are strictly forbidden.
