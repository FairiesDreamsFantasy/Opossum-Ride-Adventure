# Opossums - Steed Registry & Specification

This directory contains the 32 total crafted opossums (24 Sacred Large Jills and 8 Compact Jacks).

## Implementation Standard: "The Textbook Architecture"
Every crafted opossum must adhere to the modular 5-unit textbook implementation:
1. **Unit I: Morphometrics**: High-precision biometric profiles.
2. **Unit II: Kinematics**: Gait analysis and RK4 integration.
3. **Unit III: Acoustics**: 64-bit IEEE 754 DSP audio synthesis.
4. **Unit IV: Geometry**: Bezier spline and pattern lattice evaluation.
5. **Unit V: Lore Ecosystem**: Diverse character history and vocation profiles.

## Folder Structure
- `Animations/`: 2D/3D datasets.
- `C_Plus_Plus/`: Native individual character kernels.
- `Description/`: Lore and dimensional summaries.
- `General/`: Core identity metadata.
- `Sounds/`: Audio synthesis modules.
- `Units/`: The 5-unit scientific core.

Refer to `STANDARDIZATION.md` for specific architectural constraints.
