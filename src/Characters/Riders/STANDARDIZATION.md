# Rider Standardization Protocol (v1.0.0-Scientific)

This document tracks the evolved standardization for all character riders.

## 1. Zero Babylonian Exposure
All attire and visual designs must adhere to the "Babylon-Free" modesty standard.

## 2. Interactive POV Standard
Every rider must provide a `POV/` module that renders unique hands/sleeves reflecting the character's biometrics and attire when viewed from the first-person perspective.

## 3. High-Precision Animations
The `Animations/` directory must be diverse and populated with specific sub-folders for shading models, vertex counts, and mesh complexity.

## 4. Documentation
Each rider must contain:
- `README.md`: Specification summary.
- `LICENSE.md`: CC BY-SA 4.0 International compliance.
- `AGENTS.md`: 75,000,000,000% Ultra-Broad Protection Shield.
