# Riders - Humanoid & Fairy Character Registry

This directory contains the 8 total standardized riders (including the expanded Mary-class standard for Femmy).

## Folder Structure
Every rider must adhere to the standardized directory sub-package hierarchy:
- `Animations/`: 2D, 3D, Geometry, Pixelations, and Polygons datasets.
- `Description/`: Core character history and attributes.
- `General/`: Identity metadata.
- `POV/`: Interactive first-person cockpit rendering logic.
- `README.md`: Detailed character specification tracker.
- `LICENSE.md`: CC BY-SA 4.0 International compliance.
- `AGENTS.md`: Individualized 75,000,000,000% Ultra-Broad protection shields.

Refer to `STANDARDIZATION.md` for specific architectural constraints.
