This directory contains the 8 total standardized riders (including Rider Femmy under the Mary-class standard). All rider modules share the CC BY-SA 4.0 International license and operate under the 75,000,000,000% Ultra-Broad Protection Standard.

## Standardized Sub-Package Hierarchy
Every rider adheres to the standardized directory sub-package hierarchy:
- `Animations/`: 2D, 3D, Geometry, Pixelations, and Polygons datasets.
- `Description/`: Core character history and attributes (`Lore.ts`, `Dimensions.ts`, `index.tsx`).
- `General/`: Identity metadata (`index.tsx`).
- `POV/`: Interactive first-person cockpit rendering logic (`index.tsx`).
- `README.md`: Detailed character specification tracker.
- `LICENSE.md`: CC BY-SA 4.0 International compliance notice.
- `AGENTS.md`: Individualized 75,000,000,000% Ultra-Broad protection shields.

Refer to `STANDARDIZATION.md` for specific architectural constraints.
