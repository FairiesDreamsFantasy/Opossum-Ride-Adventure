# World 4 — The Great Outdoors, Wilderness and Mountains (`src/World/4/`)

- **Levels Directory (`Levels/`)**: Strictly `Level_1` through `Level_40` (**NO `Level_0`**, **NO `Level_N`/`Level_*`**).
- **Progression Structure**: 8 assorted 5-biome rounds cycling `[Desert, Forest, Plain, Mountains, Natural Cave]` across all 40 Wilderness arenas.
- **Sky**: Preserved cleanly across outdoor biomes; subterranean cave acoustics and spatial reverb handled by `WildernessAmbienceEngine` and `SoundEngine`.
