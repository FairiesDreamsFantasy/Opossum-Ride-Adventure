# Accessibility Commitment For Supporting Screen-Reader Users

**Opossum Ride Adventure** has a built-in screen-reader to describe current environments of this game, along with opponent scanning, position information, changing of prospective, and reading of HUD above the canvas. Also, the canvas element has an *aria-label="Opossum Ride Adventure Game View" or something similar. Also, this game supports play via desktop computers, or mobile devices. Screen-reader users and other gamers use a keyboard to interact with this game when using ANY desktop computer OSs that are currently supported, such as Windows, Linux, and Chrome OS. However; this game is not yet tested on Apple Macintosh computers just yet.
## Why adding accessibility is important
We believe adding a screen-reader to this game for blind gamers because, this game uses the "screen-reader first" approach as we develop this game by each step. However; this screen-reader that is built into this game may have these limitations, depending on a version of a game.
## If you use Orca via Linux:
You can toggle Orca's speech by pressing a modifier key and "s" to easily hear the screen-reader via a game (during game play).
The canvas element can be easily be focused, depending on your screen-reader's capability.
## If you use Voice-Over via iPad
Press Left+Right arrow keys to toggle navigation mode to off, after you are focused via a canvas element. You need a keyboard to play this game.
## If you Use NVDA Via Windows
Similar to Orca via Linux; you can accomplish the same way.
# Limitations
Here are the following limitations
## The built-in screen-reader does not:
* Announce lane positions when strafing lanes.
* Announce selected characters via "Rider Selection Screen", Opossum Selection Screen", and other parts of this game. However; a local screen-reader can still read information on this game's pages.
  * Accurately describe what you expected to describe (if use of Gemini via [Google AI Studio](https://aistudio.google.com) provided API key provided by a player), or an in-game's AI system for narrations.
  * Work like a replacement screen-reader.
