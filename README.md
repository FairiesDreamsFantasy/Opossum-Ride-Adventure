# Opossum Ride Adventure
By *Fairies Dreams & Fantasy*

## About This Game:

This is a "screen-reader first" game that has riders, and opossums to choose. Jump over obstacles, ride along paths, and gather treats.

This is a jump-and-run game is built with craftsmanship and artistry.

Dodge malicious monkeys riding moose, and dodge certain obstacles that can't be jumped over. Similar to other jump-and-run platformer games, you can attack enemies by jumping on them!
