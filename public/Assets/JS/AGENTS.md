# AGENTS.md Protection Shield - /public/Assets/JS/ Subsystems

## Scope
Protects all JavaScript asset modules across `/public/Assets/JS/` (`System/Registry`, `System/Sound`, `System/AI`, `System/Engine`, `Characters/Riders`, `Characters/Opossums`, `Characters/Monkeys`, `Characters/Moose`).

1. All JavaScript asset files must remain fully written with valid ES Module syntax.
